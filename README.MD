# ⚔️ Game Battle Arena

A terminal-based RPG game built with Python using Object-Oriented Programming (OOP).

## 🎮 Features

- ⚔️ Turn-based combat system
- 👹 Three enemies: Goblin, Wolf and Orc
- 🛒 Shop with attack upgrades and health potions
- 🪙 Gold rewards after winning battles
- ⭐ XP and leveling system
- 💾 Save and load game progress using JSON
- 📊 Player statistics

## 🛠️ Technologies

- Python 3
- Object-Oriented Programming (OOP)
- JSON

## 🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

`python main.py`
